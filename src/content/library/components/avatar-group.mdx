## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from '@/components/ui/avatar'
import { AvatarGroup, AvatarGroupAction } from '@/components/spaceui/avatar-group'
```

```tsx
<AvatarGroup stacking="left">
  <Avatar>
    <AvatarImage />
    <AvatarFallback>U1</AvatarFallback>
  </Avatar>
  <Avatar>
    <AvatarImage />
    <AvatarFallback>U2</AvatarFallback>
  </Avatar>
  <AvatarGroupAction>+4</AvatarGroupAction>
</AvatarGroup>
```

## Features

### With Actions

Use the `AvatarGroupAction` component to add an interactive trailing element. It can contain text indicating remaining users or an icon for interaction (e.g., a plus button to add members).

## API Reference

### AvatarGroup Props

| Prop       | Type                | Default   | Description                                        |
| ---------- | ------------------- | --------- | -------------------------------------------------- |
| `stacking` | `"left" \| "right"` | `"right"` | Controls the visual z-index overlap of the avatars |
