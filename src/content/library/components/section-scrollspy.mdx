Mark each block with `data-page-section` and an `h2`. The bar reads the heading (and an optional badge) then follows scroll.

## Installation

<ComponentInstallation name="components-spaceui-section-scrollspy" />

## Usage

```tsx
import * as React from 'react'
import { SectionScrollspy } from '@/components/spaceui/section-scrollspy'

export default function SpaceUI() {
  const scrollRef = React.useRef<HTMLDivElement>(null)

  return (
    <div ref={scrollRef} className="relative h-[420px] overflow-y-auto">
      <section data-page-section>
        <h2>Installation</h2>
      </section>
      <SectionScrollspy containerRef={scrollRef} />
    </div>
  )
}
```

Pass `portal` to pin it to the viewport. Omit `containerRef` to track `window` scroll.

## API Reference

| Prop           | Type                     | Default               | Description                    |
| -------------- | ------------------------ | --------------------- | ------------------------------ |
| `containerRef` | `RefObject<HTMLElement>` | —                     | Scroll root. Window if omitted |
| `selector`     | `string`                 | `[data-page-section]` | Section query                  |
| `portal`       | `boolean`                | `false`               | Render into `document.body`    |
| `className`    | `string`                 | —                     | Root class                     |
