## API Reference

### PhoneInput

The main component for entering phone numbers with country selection.

| Prop             | Type                        | Default     | Description                                                |
| :--------------- | :-------------------------- | :---------- | :--------------------------------------------------------- |
| `value`          | `string`                    | -           | The current phone number value in E.164 format.            |
| `onChange`       | `(value: string) => void`   | -           | Callback fired when the value changes.                     |
| `variant`        | `"sm" \| "default" \| "lg"` | `"default"` | The vertical size of the input and country selector.       |
| `popupClassName` | `string`                    | -           | Additional CSS classes for the country selection dropdown. |
| `defaultCountry` | `Country`                   | -           | The default country selected if no value is provided.      |
| `placeholder`    | `string`                    | -           | Placeholder text for the phone number input.               |
| `className`      | `string`                    | -           | Additional CSS classes for the root container.             |
| `disabled`       | `boolean`                   | `false`     | Whether the input and country selector are disabled.       |

---

### Utilities

The component re-exports essential phone number utilities:

```tsx
import {
  PhoneInput,
  isValidPhoneNumber,
  formatPhoneNumber,
  formatPhoneNumberIntl,
  isPossiblePhoneNumber,
  getCountryCallingCode,
} from '@/components/spaceui/phone-input'
```

- **`isValidPhoneNumber(value)`**: Checks if the phone number is valid according to international metadata.
- **`formatPhoneNumber(value)`**: Formats the phone number in national format.
- **`formatPhoneNumberIntl(value)`**: Formats the phone number in international format (e.g. `+1 213 373 4253`).
- **`isPossiblePhoneNumber(value)`**: Quick length check to see if the number could be possible.
- **`getCountryCallingCode(country)`**: Returns the calling code for a given ISO country code (e.g. `'FR'` -> `'33'`).
