## Usage

```tsx
export default function Example() {
  return <InteractiveChecklist />
}
```

## Props

| Prop            | Type              | Default          | Description                       |
| --------------- | ----------------- | ---------------- | --------------------------------- |
| `initialItems`  | `ChecklistItem[]` | `DEFAULT_TASKS`  | Initial checklist tasks           |
| `title`         | `string`          | `'Sprint Tasks'` | Checklist title                   |
| `corner`        | `number`          | `24`             | Corner radius in px               |
| `onCompleteAll` | `() => void`      | `—`              | Triggered when all items are done |
