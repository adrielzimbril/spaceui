## Features

- **Dynamic Proximity Physics**: Cells smoothly adjust border-radius and inset within a configurable radius around the pointer.
- **Shape Controls**: Switch seamlessly between `square`, `rounded`, and `full` (circle) corner styles.
- **Responsive Layout**: Automatically calculates rows and columns to fill 100% of container width and height.
