## Usage

```tsx

const { width, height } = useWindowSize()
```

## API Reference

### Parameters / Props

_None_

### Return Value

| Property | Type     | Description      |
| :------- | :------- | :--------------- |
| `width`  | `number` | Viewport width.  |
| `height` | `number` | Viewport height. |
