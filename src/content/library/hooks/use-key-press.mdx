## Usage

```tsx
import { useKeyPress } from '@/hooks/use-key-press'

const isEscape = useKeyPress('Escape')
```

## API Reference

### Parameters / Props

| Parameter   | Type     | Default    | Description |
| :---------- | :------- | :--------- | :---------- |
| `targetKey` | `string` | _required_ | Key name.   |

### Return Value

| Return Type | Description         |
| :---------- | :------------------ |
| `boolean`   | True while pressed. |
