## Usage

```tsx
import { useOrientation } from '@/hooks/use-orientation'

const { angle, type } = useOrientation()
```

## API Reference

### Parameters / Props

_None_

### Return Value

| Property | Type     | Description              |
| :------- | :------- | :----------------------- |
| `angle`  | `number` | Angle in degrees.        |
| `type`   | `string` | 'portrait-primary', etc. |
