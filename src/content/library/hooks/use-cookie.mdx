## Usage

```tsx
import { useCookie } from '@/hooks/use-cookie'

const [theme, setTheme, removeTheme] = useCookie('theme', 'dark')
```

## API Reference

### Parameters / Props

| Parameter      | Type     | Default     | Description      |
| :------------- | :------- | :---------- | :--------------- |
| `name`         | `string` | _required_  | Cookie name.     |
| `initialValue` | `string` | `undefined` | Initial default. |

### Return Value

| Return Type                                           | Description         |
| :---------------------------------------------------- | :------------------ |
| `[string \| null, (val: string) => void, () => void]` | Tuple cookie state. |
