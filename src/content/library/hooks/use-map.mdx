## Usage

```tsx
import { useMap } from '@/hooks/use-map'

const [map, actions] = useMap([['key', 'val']])
actions.set('key', 'newVal')
```

## API Reference

### Parameters / Props

| Parameter        | Type       | Default | Description    |
| :--------------- | :--------- | :------ | :------------- |
| `initialEntries` | `[K, V][]` | `[]`    | Initial pairs. |

### Return Value

| Property  | Type        | Description                    |
| :-------- | :---------- | :----------------------------- |
| `map`     | `Map<K, V>` | Reactive Map instance.         |
| `actions` | `Object`    | `set`, `delete`, `clear`, etc. |
