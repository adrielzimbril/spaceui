## Usage

```tsx
import { useBatteryStatus } from '@/hooks/use-battery-status'

const { level, charging } = useBatteryStatus()
```

## API Reference

### Parameters / Props

_None_

### Return Value

| Property   | Type      | Description            |
| :--------- | :-------- | :--------------------- |
| `level`    | `number`  | Battery charge 0 to 1. |
| `charging` | `boolean` | Connected to power.    |
