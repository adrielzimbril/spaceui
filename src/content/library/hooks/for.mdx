## Usage

````tsx
import { For } from '@/components/for'

import { For } from '@/components/for'```

```tsx
<For each={['A', 'B', 'C']} fallback={<p>Empty</p>}>
  {(item, i) => <div key={i}>{item}</div>}
</For>
````

## API Reference

### Parameters / Props

| Prop       | Type                                    | Default    | Description           |
| :--------- | :-------------------------------------- | :--------- | :-------------------- |
| `each`     | `T[] \| null \| undefined`              | _required_ | Array to map.         |
| `fallback` | `ReactNode`                             | `null`     | Empty state fallback. |
| `children` | `(item: T, index: number) => ReactNode` | _required_ | Item renderer.        |

### Return Value

| Return Type | Description    |
| :---------- | :------------- |
| `ReactNode` | Rendered list. |
