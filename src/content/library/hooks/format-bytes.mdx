## Usage

```tsx
import { formatBytes, parseBytes } from '@/utils/format-bytes'

formatBytes(15728640) // => "15.00 MB"
parseBytes('15MB') // => 15728640
```

## API Reference

### Parameters / Props

| Parameter          | Type     | Default    | Description     |
| :----------------- | :------- | :--------- | :-------------- |
| `bytes`            | `number` | _required_ | Numeric bytes.  |
| `options.decimals` | `number` | `2`        | Decimal digits. |

### Return Value

| Return Type | Description                 |
| :---------- | :-------------------------- |
| `string`    | Formatted file size string. |
