## Usage

```tsx
import { useCharacterLimit } from '@/hooks/use-character-limit'

const { value, remaining, percentage, onChange } = useCharacterLimit({ maxLength: 100 })
```

## API Reference

### Parameters / Props

| Parameter           | Type     | Default    | Description |
| :------------------ | :------- | :--------- | :---------- |
| `options.maxLength` | `number` | _required_ | Max length. |

### Return Value

| Property     | Type     | Description         |
| :----------- | :------- | :------------------ |
| `value`      | `string` | Current text.       |
| `remaining`  | `number` | Leftover quota.     |
| `percentage` | `number` | Percentage (0-100). |
