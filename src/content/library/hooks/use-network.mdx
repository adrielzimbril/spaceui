## Usage

```tsx
import { useNetwork } from '@/hooks/use-network'

const { isOnline, downlink, effectiveType } = useNetwork()
```

## API Reference

### Parameters / Props

_None_

### Return Value

| Property        | Type                  | Description                |
| :-------------- | :-------------------- | :------------------------- |
| `isOnline`      | `boolean`             | Internet connection state. |
| `downlink`      | `number \| undefined` | Bandwidth in Mbps.         |
| `effectiveType` | `string \| undefined` | Connection tier.           |
