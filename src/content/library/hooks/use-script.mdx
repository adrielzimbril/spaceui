## Usage

```tsx
import { useScript } from '@/hooks/use-script'

const status = useScript('https://example.com/lib.js')
```

## API Reference

### Parameters / Props

| Parameter | Type     | Default    | Description |
| :-------- | :------- | :--------- | :---------- |
| `src`     | `string` | _required_ | Script URL. |

### Return Value

| Return Type                                 | Description     |
| :------------------------------------------ | :-------------- |
| `'idle' \| 'loading' \| 'ready' \| 'error'` | Loading status. |
