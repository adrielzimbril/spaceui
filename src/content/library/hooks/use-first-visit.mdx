## Usage

```tsx
import { useFirstVisit } from '@/hooks/use-first-visit'

const isFirst = useFirstVisit('welcome_popup')
```

## API Reference

### Parameters / Props

| Parameter | Type     | Default    | Description |
| :-------- | :------- | :--------- | :---------- |
| `key`     | `string` | _required_ | Visit key.  |

### Return Value

| Return Type | Description          |
| :---------- | :------------------- |
| `boolean`   | True on first visit. |
