## Usage

```tsx
import { bindEvent } from '@/utils/event'

const unbind = bindEvent(window, 'resize', () => onResize())
```

## API Reference

### Parameters / Props

| Parameter  | Type            | Default    | Description     |
| :--------- | :-------------- | :--------- | :-------------- |
| `target`   | `EventTarget`   | _required_ | DOM target.     |
| `type`     | `string`        | _required_ | Event name.     |
| `listener` | `EventListener` | _required_ | Event callback. |

### Return Value

| Return Type  | Description       |
| :----------- | :---------------- |
| `() => void` | Cleanup function. |
