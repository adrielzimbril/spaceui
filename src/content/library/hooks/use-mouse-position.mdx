## Usage

```tsx
import { useMousePosition } from '@/hooks/use-mouse-position'

const { x, y } = useMousePosition()
```

## API Reference

### Parameters / Props

_None_

### Return Value

| Property | Type     | Description             |
| :------- | :------- | :---------------------- |
| `x`      | `number` | X coordinate in pixels. |
| `y`      | `number` | Y coordinate in pixels. |
