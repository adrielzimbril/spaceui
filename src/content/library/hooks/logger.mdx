## Usage

```tsx
import { logger } from '@/utils/logger'

const log = logger.create('AUTH')
log.info('User logged in')
```

## API Reference

### Parameters / Props

| Method                     | Description            |
| :------------------------- | :--------------------- |
| `logger.create(namespace)` | Creates scoped logger. |
| `log.info(...args)`        | Info level log.        |
| `log.warn(...args)`        | Warning level log.     |
| `log.error(...args)`       | Error level log.       |

### Return Value

_Logger instance._
