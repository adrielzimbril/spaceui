## Usage

````tsx
import { If } from '@/components/if'

import { If } from '@/components/if'```

```tsx
<If condition={isLoggedIn} fallback={<p>Logged Out</p>}>
  <p>Welcome back!</p>
</If>
````

## API Reference

### Parameters / Props

| Prop        | Type                         | Default    | Description        |
| :---------- | :--------------------------- | :--------- | :----------------- |
| `condition` | `boolean \| (() => boolean)` | _required_ | Boolean condition. |
| `fallback`  | `ReactNode`                  | `null`     | Fallback branch.   |

### Return Value

| Return Type | Description      |
| :---------- | :--------------- |
| `ReactNode` | Rendered output. |
