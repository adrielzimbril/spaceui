## Usage

```tsx
import { slugifyHeadline } from '@/utils/format-content'

slugifyHeadline('Getting Started with React!') // => "getting-started-with-react"
```

## API Reference

### Parameters / Props

| Parameter   | Type     | Default    | Description |
| :---------- | :------- | :--------- | :---------- |
| `text`      | `string` | _required_ | Input text. |
| `maxLength` | `number` | _required_ | Max length. |

### Return Value

| Return Type | Description       |
| :---------- | :---------------- |
| `string`    | Truncated string. |
