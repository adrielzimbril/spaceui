## Usage

```tsx
import { useInterval } from '@/hooks/use-interval'

const { start, stop } = useInterval(() => tick(), 1000)
```

## API Reference

### Parameters / Props

| Parameter  | Type             | Default    | Description    |
| :--------- | :--------------- | :--------- | :------------- |
| `callback` | `() => void`     | _required_ | Tick function. |
| `delay`    | `number \| null` | `null`     | Delay in ms.   |

### Return Value

| Property | Type                       | Description      |
| :------- | :------------------------- | :--------------- |
| `start`  | `(delay?: number) => void` | Starts interval. |
| `stop`   | `() => void`               | Pauses interval. |
