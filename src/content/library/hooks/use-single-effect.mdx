## Usage

```tsx
import { useSingleEffect } from '@/hooks/use-single-effect'

useSingleEffect(() => {
  initAnalytics()
})
```

## API Reference

### Parameters / Props

| Parameter | Type         | Default    | Description               |
| :-------- | :----------- | :--------- | :------------------------ |
| `effect`  | `() => void` | _required_ | Run-once effect function. |

### Return Value

_Returns void._
