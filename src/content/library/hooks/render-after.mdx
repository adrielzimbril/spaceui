## Usage

````tsx
import { RenderAfter } from '@/components/render-after'

import { RenderAfter } from '@/components/render-after'```

```tsx
<RenderAfter delay={1000}>
  <Popup />
</RenderAfter>
````

## API Reference

### Parameters / Props

| Prop       | Type        | Default    | Description          |
| :--------- | :---------- | :--------- | :------------------- |
| `delay`    | `number`    | _required_ | Delay in ms.         |
| `fallback` | `ReactNode` | `null`     | Loading placeholder. |

### Return Value

| Return Type | Description      |
| :---------- | :--------------- |
| `ReactNode` | Rendered output. |
