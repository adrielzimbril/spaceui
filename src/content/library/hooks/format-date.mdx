## Usage

```tsx
import { getHumanDate, formatDateDiff } from '@/utils/format-date'

getHumanDate(new Date(), 'short')
formatDateDiff(new Date(Date.now() - 3600000)) // => "1 hour ago"
```

## API Reference

### Parameters / Props

| Parameter | Type                       | Default        | Description   |
| :-------- | :------------------------- | :------------- | :------------ |
| `date`    | `Date \| number \| string` | _required_     | Target date.  |
| `format`  | `string`                   | `'yyyy-MM-dd'` | Date pattern. |

### Return Value

| Return Type | Description            |
| :---------- | :--------------------- |
| `string`    | Formatted date string. |
