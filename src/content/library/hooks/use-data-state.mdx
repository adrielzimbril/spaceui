## Usage

```tsx
import { useDataState } from '@/hooks/use-data-state'

const state = useDataState(isOpen) // 'open' | 'closed'
```

## API Reference

### Parameters / Props

| Parameter | Type      | Default    | Description   |
| :-------- | :-------- | :--------- | :------------ |
| `isOpen`  | `boolean` | _required_ | Open boolean. |

### Return Value

| Return Type          | Description        |
| :------------------- | :----------------- |
| `'open' \| 'closed'` | Data state string. |
