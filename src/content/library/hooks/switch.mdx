## Usage

````tsx
import { Switch, Case, Default } from '@/components/switch'

import { Switch, Case, Default } from '@/components/switch'```

```tsx
<Switch>
  <Case condition={tab === 'home'}>
    <Home />
  </Case>
  <Case condition={tab === 'profile'}>
    <Profile />
  </Case>
  <Default>
    <Settings />
  </Default>
</Switch>
````

## API Reference

### Parameters / Props

| Component     | Prop        | Description                  |
| :------------ | :---------- | :--------------------------- |
| `<Switch />`  | `children`  | Container for Case elements. |
| `<Case />`    | `condition` | Branch condition.            |
| `<Default />` | `children`  | Fallback branch.             |

### Return Value

| Return Type | Description     |
| :---------- | :-------------- |
| `ReactNode` | Matched branch. |
