## Usage

```tsx
import { sleep } from '@/utils/sleep'

await sleep(1000) // delays for 1s
```

## API Reference

### Parameters / Props

| Parameter | Type     | Default    | Description            |
| :-------- | :------- | :--------- | :--------------------- |
| `ms`      | `number` | _required_ | Delay in milliseconds. |

### Return Value

| Return Type     | Description           |
| :-------------- | :-------------------- |
| `Promise<void>` | Resolves after delay. |
