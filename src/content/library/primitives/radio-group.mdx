## Usage

```tsx
import { Label } from '@/components/ui/label'
import { Radio, RadioGroup } from '@/components/ui/radio-group'
```

```tsx
<RadioGroup defaultValue="next">
  <Label>
    <Radio value="next" /> Next.js
  </Label>
  <Label>
    <Radio value="vite" /> Vite
  </Label>
  <Label>
    <Radio value="astro" /> Astro
  </Label>
</RadioGroup>
```

## Anatomy

```tsx
<RadioGroup>
  <Radio value="1">
    <RadioIndicator />
  </Radio>
</RadioGroup>
```

## Features

### Sizes

Radio buttons in `sm`, `default`, and `lg` sizes.

<ComponentPreview name="demo-p-radio-group-02" />

## Accessibility

- Follows the [WAI-ARIA Radio Group Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/).

### Keyboard Interactions

| Key                                          | Action                                        |
| :------------------------------------------- | :-------------------------------------------- |
| <Kbd>ArrowDown</Kbd> / <Kbd>ArrowRight</Kbd> | Moves selection to the next radio option.     |
| <Kbd>ArrowUp</Kbd> / <Kbd>ArrowLeft</Kbd>    | Moves selection to the previous radio option. |

## API Reference

### RadioGroup

Root component. Styled wrapper for `RadioGroup.Root` from Base UI with flex column layout.

### Radio

Individual radio button. Styled wrapper for `Radio.Root` from Base UI with built-in indicator. Also exported as `RadioGroupItem`.
