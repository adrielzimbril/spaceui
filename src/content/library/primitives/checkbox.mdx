## Features

### Sizes

Checkboxes in `sm`, `default`, and `lg` sizes.

<ComponentPreview name="demo-p-checkbox-02" />

## Accessibility

- Follows the [WAI-ARIA Checkbox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/).

### Keyboard Interactions

| Key              | Action                                                    |
| :--------------- | :-------------------------------------------------------- |
| <Kbd>Space</Kbd> | Toggles the checkbox state between checked and unchecked. |

## API Reference

### Checkbox

Styled wrapper for `Checkbox.Root` from Base UI. Includes a built-in indicator with checkmark and indeterminate icons.
