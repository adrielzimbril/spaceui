## Polymorphic Routing (`render`)

Because the `Link` primitive is built on **Base UI**, it renders as a native HTML `<a>` tag by default. This makes it 100% universal across all React setups (Vite, Next.js, Remix, Astro, TanStack Start).

When building a Next.js application, you can pass Next.js `NextLink` to the `render` prop to enable client-side navigation, automatic prefetching, and router cache:

```tsx
import NextLink from 'next/link'
import { Link } from '@/components/ui/link'

export function NavLink() {
  return <Link render={<NextLink href="/dashboard" />}>Dashboard</Link>
}
```

## API Reference

### Link Props

| Prop        | Type                                                                                         | Default     | Description                                              |
| :---------- | :------------------------------------------------------------------------------------------- | :---------- | :------------------------------------------------------- |
| `variant`   | `"default" \| "secondary" \| "ghost" \| "outline" \| "destructive" \| "destructive-outline"` | `"default"` | Controls the visual text styling or button styling       |
| `size`      | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"`         | `"default"` | Controls button size when `asButton` is true             |
| `underline` | `boolean`                                                                                    | `false`     | When true, adds hover underline effect with offset       |
| `asButton`  | `boolean`                                                                                    | `false`     | When true, applies button variant and dimensions styling |
| `render`    | `React.ReactElement`                                                                         | -           | Polymorphic render prop (e.g. Next.js Link)              |
