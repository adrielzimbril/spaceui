**Space UI is a distribution of React components** built with [Tailwind CSS](https://tailwindcss.com/), [Motion](https://motion.dev/), and [Base UI](https://base-ui.com/), based on the shadcn registry format. Our goal is to help anyone build tasteful, accessible, Motion‑powered interfaces while keeping sites ultra-fast, sensory, and maintainable.

## Not a library—an open component distribution

Like [shadcn/ui](https://ui.shadcn.com/), **Space UI is not a typical install‑from‑NPM library**. It’s an open collection you can **copy, modify, and customize** directly in your codebase. This “open code” approach gives you maximum flexibility without wrapper overhead or styling workarounds.

## What’s included

1. **Primitives (animated)**: Core building blocks with physics & animation baked in, ported and extended from Base UI.
2. **Components & Blocks**: Complex components, sensory avatars, charts, grids, and ready-to-use section blocks.
3. **Sensory Hooks & DX**: Sensory UI feedback, sound system, direction, and flow controllers.
4. **Iconography**: Clean vector icons utilizing Tabler Icons for components and Lucide for primitives.

## Why Space UI?

1. **Open source & copy‑first**: Direct access to source so you can adapt components at their core to your design system.
2. **Sensory & Animation‑first**: Consistent, composable physics and micro-interactions that make interfaces feel alive.
3. **Performance & accessibility**: Sensible defaults, WCAG compliance, and reduced-motion safety.
4. **Base UI & Radix support**: Built on headless primitives while keeping source open and fully customizable.

## AI-Enhanced Workflow

Space UI is designed from the ground up to be **AI-friendly**, making it easier for language models to understand and modify your UI.

- **llms.txt**: Access our [llms.txt](/llms.txt) file for a structured map of our documentation and architecture optimized for AI agents.
- **Copy Markdown**: Every page includes a **Copy Markdown** feature, allowing you to instantly feed documentation or code into your AI-driven development workflows.
