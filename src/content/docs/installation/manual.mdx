This guide covers setting up Space UI manually—from configuring **`components.json`** for registry resolution to zero-CLI copy-pasting for custom stacks and monorepos.

<Callout>
  **Full Code Ownership:** Space UI components are open and unbundled. You have complete freedom to customize, tweak
  styles, and adapt them directly in your codebase.
</Callout>

<Steps>

<Step>

### Install Core Dependencies

Install Base UI, Motion, and class utility dependencies:

<InstallCommandBlock
  commands={{
    pnpm: 'pnpm add @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
    npm: 'npm install @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
    yarn: 'yarn add @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
    bun: 'bun add @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
  }}
/>

</Step>

<Step>

### Configure `components.json`

Create or update `components.json` at the root of your project to connect the `@spaceui` registry namespace:

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "ui": "@/components/ui",
    "blocks": "@/components/blocks",
    "lib": "@/lib",
    "utils": "@/lib/utils",
    "hooks": "@/hooks"
  },
  "registries": {
    "@spaceui": "https://www.spaceui.one/r/{name}.json"
  }
}
```

</Step>

<Step>

### Add Class Merging Utility (`lib/utils.ts`)

Create `lib/utils.ts` to provide the `cn()` helper used throughout all Space UI primitives:

```ts title="lib/utils.ts"
export { cn, type ClassValue } from 'cn'
```

</Step>

## `components.json` Schema Reference

| Property                    | Type      | Description                                                                                              |
| :-------------------------- | :-------- | :------------------------------------------------------------------------------------------------------- |
| **`style`**                 | `string`  | Style preset. Set to `"base-nova"` for Base UI and squircle token support.                               |
| **`rsc`**                   | `boolean` | Set to `true` for Next.js App Router (React Server Components). When `false`, all files are client-only. |
| **`tsx`**                   | `boolean` | Set to `true` to generate `.tsx`/`.ts` files, or `false` for `.jsx`/`.js`.                               |
| **`tailwind.css`**          | `string`  | Relative path to your global CSS stylesheet (e.g. `app/globals.css` or `src/index.css`).                 |
| **`tailwind.baseColor`**    | `string`  | Base palette color (`neutral`, `zinc`, `slate`, `gray`, `stone`).                                        |
| **`tailwind.cssVariables`** | `boolean` | Set to `true` to enable CSS variables (`--background`, `--foreground`).                                  |
| **`aliases`**               | `object`  | Mapping between logical imports and your project directory structure.                                    |
| **`registries`**            | `object`  | Remote registry namespace mapping (e.g. `"@spaceui": "https://www.spaceui.one/r/{name}.json"`).          |

---

## Multi-Registry Namespaces

With the `@spaceui` registry configured, you can install any component with:

```bash
npx shadcn@latest add @spaceui/dialog @spaceui/button
```

The CLI queries `https://www.spaceui.one/r/{name}.json`, resolves the component code and sub-dependencies, rewrites imports according to your local `aliases`, and places files into your `components/ui/` directory.

---

## Custom Path Aliases & Monorepos

For monorepo structures (e.g. Turborepo, Nx) or custom folder hierarchies, adjust the `aliases` block:

```json title="components.json"
{
  "aliases": {
    "components": "@/shared/components",
    "ui": "@/shared/components/ui",
    "blocks": "@/shared/components/blocks",
    "lib": "@/shared/lib",
    "utils": "@/shared/utils",
    "hooks": "@/shared/hooks"
  }
}
```
