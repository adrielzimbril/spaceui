Space UI is an open distribution of React components built on top of **React 19**, **Base UI**, **Tailwind CSS v4**, and **Motion**. It works seamlessly with the official `shadcn` CLI through custom registries.

<Callout>
  **Zero-lockin open code:** Space UI components are not a heavy NPM dependency. They install directly into your
  codebase, giving you full ownership to inspect, edit, and style every line of code.
</Callout>

## Prerequisites & Compatibility

Ensure your project environment meets the minimum version requirements:

| Technology       | Minimum Version | Notes                                                                 |
| :--------------- | :-------------- | :-------------------------------------------------------------------- |
| **React**        | `≥ 19.0.0`      | Full support for React 19 Actions, Server Components, and Transitions |
| **Tailwind CSS** | `≥ 4.0.0`       | Built natively for CSS-first `@import "tailwindcss";` architecture    |
| **Motion**       | `≥ 12.0.0`      | Fluid physics, layout animations, and gesture interactions            |
| **Base UI**      | `≥ 1.7.0`       | Headless, accessible primitives powering menus, dialogs, and popovers |

## Quick Start (CLI)

If you already have a React project with Tailwind CSS configured, integrate Space UI in three simple steps:

<Steps>

<Step>

### Initialize the Space UI Preset

Run the `init` command to automatically configure your `components.json`, color variables, and squircle utility classes:

<InstallCommandBlock
  commands={{
    pnpm: 'pnpm dlx shadcn@latest init https://www.spaceui.one/r/lib-style.json',
    npm: 'npx shadcn@latest init https://www.spaceui.one/r/lib-style.json',
    yarn: 'yarn dlx shadcn@latest init https://www.spaceui.one/r/lib-style.json',
    bun: 'bunx --bun shadcn@latest init https://www.spaceui.one/r/lib-style.json',
  }}
/>

</Step>

<Step>

### Add Components

Install any primitive or component directly from the `@spaceui` registry:

<InstallCommandBlock isShadcn packages="@spaceui/dialog @spaceui/button" />

<Callout type="info">
  Shared dependencies like `@base-ui/react`, `motion`, and `@spaceui/*` primitives are resolved and downloaded
  automatically by the CLI.
</Callout>

</Step>

<Step>

### Import and Use

Import the installed component into your layout or page:

```tsx title="app/page.tsx"
import { Dialog, DialogTrigger, DialogPopup, DialogTitle, DialogDescription, DialogClose } from '@/components/ui/dialog'
import { Button } from '@/components/ui/button'

export default function Page() {
  return (
    <Dialog>
      <DialogTrigger render={<Button variant="primary">Open Dialog</Button>} />
      <DialogPopup>
        <DialogTitle>Welcome to Space UI</DialogTitle>
        <DialogDescription>
          State of the art animations, accessible Base UI primitives, and sensory micro-interactions.
        </DialogDescription>
        <div className="flex justify-end gap-2 mt-4">
          <DialogClose render={<Button variant="secondary">Dismiss</Button>} />
          <Button variant="primary">Confirm</Button>
        </div>
      </DialogPopup>
    </Dialog>
  )
}
```

</Step>

</Steps>
