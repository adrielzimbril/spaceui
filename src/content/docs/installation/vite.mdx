---
title: Vite + React
description: Setup Space UI in a modern Vite React SPA with Tailwind CSS v4 and TypeScript path aliases.
---

This guide walks you through setting up Space UI in a **Vite + React 19** Single Page Application using **Tailwind CSS v4** and the official `@tailwindcss/vite` plugin.

<Callout>
  **Path Aliases:** Vite requires configuring path resolution in `vite.config.ts` and `tsconfig.json` so that the
  `@/components` aliases work seamlessly with the `shadcn` CLI.
</Callout>

<Steps>

<Step>

### Create a Vite Project

Scaffold a new Vite React application with TypeScript:

<InstallCommandBlock
  commands={{
    pnpm: 'pnpm create vite my-app --template react-ts',
    npm: 'npm create vite@latest my-app -- --template react-ts',
    yarn: 'yarn create vite my-app --template react-ts',
    bun: 'bun create vite my-app --template react-ts',
  }}
/>

</Step>

<Step>

### Install Tailwind CSS v4 & Core Dependencies

Install `@tailwindcss/vite`, Tailwind CSS v4, Base UI, Motion, and utility libraries:

<InstallCommandBlock
  commands={{
    pnpm: 'pnpm add -D @tailwindcss/vite tailwindcss @types/node && pnpm add @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
    npm: 'npm install -D @tailwindcss/vite tailwindcss @types/node && npm install @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
    yarn: 'yarn add -D @tailwindcss/vite tailwindcss @types/node && yarn add @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
    bun: 'bun add -d @tailwindcss/vite tailwindcss @types/node && bun add @base-ui/react motion cn class-variance-authority lucide-react @tabler/icons-react',
  }}
/>

</Step>

<Step>

### Configure Path Aliases in `vite.config.ts`

Update `vite.config.ts` to add the `@` path alias and load the Tailwind CSS plugin:

```ts title="vite.config.ts"
import path from 'path'
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

</Step>

<Step>

### Update `tsconfig.json` and `tsconfig.app.json`

Add path mappings to `tsconfig.app.json` (or `tsconfig.json`):

```json title="tsconfig.app.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

</Step>

<Step>

<Step>

### Initialize Space UI Preset

Run the preset initializer to create `components.json`:

<InstallCommandBlock

    bun: 'bunx --bun shadcn@latest init https://www.spaceui.one/r/lib-style.json',
  }}
/>

</Step>
