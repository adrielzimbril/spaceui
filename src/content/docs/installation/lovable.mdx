## Lovable.dev

**Lovable** natively supports custom shadcn registries. You can add the Space UI registry directly in your project settings:

<Steps>

<Step>

### Configure the Registry Endpoint

In your Lovable project, open **Settings → Registries** (or in `components.json`) and add:

```json title="components.json"
{
  "registries": {
    "@spaceui": "https://www.spaceui.one/r/{name}.json"
  }
}
```

</Step>

<Step>

### Prompt Lovable with Space UI Primitives

Use specific component handles in your prompt instructions:

```text
Build a modern dashboard settings view with:
- Tabs using @spaceui/tabs
- Modal dialog for user invitations using @spaceui/dialog
- Button controls from @spaceui/button with squircle radius
- Follow the design tokens and dark mode styling from Space UI
```

</Step>

</Steps>

## Bolt.new

**Bolt.new** runs in-browser WebContainer environments. To use Space UI inside Bolt:

<Steps>

<Step>

### Initialize Space UI in WebContainer Terminal

Run the standard initialization in the Bolt terminal:

```bash
npx shadcn@latest init https://www.spaceui.one/r/lib-style.json -y
```

</Step>

<Step>

### Add Space UI Components

Install any required primitives directly:

```bash
npx shadcn@latest add https://www.spaceui.one/r/primitives-dialog.json https://www.spaceui.one/r/primitives-button.json -y
```

</Step>

</Steps>

## Cursor & Windsurf Rules (`.cursorrules`)

Save a `.cursorrules` (or `.windsurfrules`) file in the root of your repository to ensure your AI assistant always recommends and writes Space UI code:

```markdown title=".cursorrules"
# Space UI Project Guidelines

You are an expert React 19 & Tailwind CSS v4 developer working with Space UI.

## Core Stack

- React 19 (Server & Client Components)
- Base UI headless primitives (@base-ui/react)
- Motion for fluid physics and micro-interactions (motion)
- Tailwind CSS v4 (@import "tailwindcss")

## Component Installation

When asked to add or use new UI components:

1. Always check if the component exists in the Space UI registry (@spaceui).
2. Install via shadcn CLI:
   npx shadcn@latest add @spaceui/<component-name>
3. Import from `@/components/ui/<component-name>`

## Theming & Styling Rules

- Use semantic color tokens: `bg-background`, `text-foreground`, `border-border`, `bg-muted`, `text-muted-foreground`.
- Use squircle corner classes (`rounded-sm`, `rounded-md`, `rounded-lg`) for cards and dialogs.
- Use `relative isolate` on page wrappers to prevent portal z-index collisions.
- Reference documentation schemas from: https://www.spaceui.one/llms.txt
```
