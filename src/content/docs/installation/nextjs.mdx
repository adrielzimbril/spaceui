This guide walks you through setting up Space UI in a modern **Next.js** application with the **App Router**, **React 19**, and **Tailwind CSS v4**.

<Callout>
  Space UI components are fully compatible with Next.js Server Components. Interactive primitives automatically contain
  the `'use client'` directive where necessary.
</Callout>

<Steps>

<Step>

### Create a Next.js Project

Initialize a new Next.js application with TypeScript, Tailwind CSS, and App Router:

<InstallCommandBlock
  commands={{
    pnpm: 'pnpm create next-app@latest my-app --typescript --tailwind --eslint --app',
    npm: 'npx create-next-app@latest my-app --typescript --tailwind --eslint --app',
    yarn: 'yarn create next-app my-app --typescript --tailwind --eslint --app',
    bun: 'bun create next-app my-app --typescript --tailwind --eslint --app',
  }}
/>

</Step>

<Step>

### Initialize Space UI Preset

Run the official initialization command to configure the Space UI design tokens, Base UI dependencies, and squircle utilities:

<InstallCommandBlock
  commands={{
    pnpm: 'pnpm dlx shadcn@latest init https://www.spaceui.one/r/lib-style.json',
    npm: 'npx shadcn@latest init https://www.spaceui.one/r/lib-style.json',
    yarn: 'yarn dlx shadcn@latest init https://www.spaceui.one/r/lib-style.json',
    bun: 'bunx --bun shadcn@latest init https://www.spaceui.one/r/lib-style.json',
  }}
/>

</Step>

<Step>

### Configure `components.json`

Ensure your `components.json` includes the `@spaceui` registry namespace alongside your project path aliases:

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "ui": "@/components/ui",
    "blocks": "@/components/blocks",
    "lib": "@/lib",
    "utils": "@/lib/utils",
    "hooks": "@/hooks"
  },
  "registries": {
    "@spaceui": "https://www.spaceui.one/r/{name}.json"
  }
}
```

</Step>

<Step>

### Setup Stacking Context in `app/layout.tsx`

Add the `relative isolate` utility class to your application wrapper. This ensures portaled elements (dialogs, tooltips, select menus) layer above sticky headers without `z-index` conflicts:

```tsx title="app/layout.tsx"
import type { Metadata } from 'next'
import { Inter } from 'next/font/google'
import './globals.css'

const inter = Inter({ subsets: ['latin'] })

export const metadata: Metadata = {
  title: 'My App',
  description: 'Built with Space UI and Next.js',
}

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body className={`${inter.className} min-h-screen bg-background text-foreground antialiased`}>
        <div className="relative isolate flex min-h-svh flex-col">{children}</div>
      </body>
    </html>
  )
}
```

</Step>

## Tips & Best Practices

<Callout type="tip">
  **React 19 Server Components:** You can import and render Space UI primitives in Server Components without adding
  `'use client'` to your page file, because the internal primitives encapsulate client boundaries directly.
</Callout>
