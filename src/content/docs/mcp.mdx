---
title: Model Context Protocol (MCP)
description: Connect Claude Code, Cursor, VS Code, and Windsurf to Space UI's component registry using MCP.
---

The **Model Context Protocol (MCP)** allows AI assistants to query the Space UI registry directly inside your editor. When enabled, your AI coding agent can search components, inspect TypeScript signatures, and install primitives without leaving the chat.

<Callout>
  Space UI leverages the official **shadcn MCP server**. Once configured, any `@spaceui` primitive can be discovered and
  installed autonomously by your AI tools.
</Callout>

---

## Manual Configuration

If you prefer adding the MCP server manually, save the corresponding JSON snippet in your project or global configuration directory:

<SpaceCodeTabs defaultValue="claude">
  <TabsList>
    <TabsTab value="claude">Claude Code</TabsTab>
    <TabsTab value="cursor">Cursor</TabsTab>
    <TabsTab value="vscode">VS Code</TabsTab>
    <TabsTab value="windsurf">Windsurf</TabsTab>
  </TabsList>
  <TabsPanel value="claude">

```json title=".mcp.json"
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

  </TabsPanel>
  <TabsPanel value="cursor">

```json title=".cursor/mcp.json"

```

  </TabsPanel>
