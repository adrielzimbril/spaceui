Space UI is engineered from the ground up for both human developers and **autonomous AI coding agents** (Claude Code, Cursor, Windsurf, GitHub Copilot, Codex, and Antigravity).

Thanks to standard shadcn registry schemas, headless Base UI primitives, and typed Motion animations, AI models can inspect, install, compose, and refactor Space UI components with zero hallucination.

## Best Practices for Agent Prompts

To get the highest quality code from your AI assistant:

### 1. Specify Component Handles

Always reference the exact `@spaceui/<component>` identifier so the agent fetches the official registry item:

```text
Add an interactive notification list using @spaceui/notification-list and @spaceui/badge.
```

### 2. Combine with Specialized Skills

Ask your agent to apply relevant engineering skills during code generation or code review:

```text
Review this dialog component. Apply the better-accessibility skill to verify keyboard traps and aria-describedby bindings.
```

### 3. Use Copy Markdown for Context

If your agent does not have live MCP access, click the **"Copy Markdown"** button at the top of any component page and paste the complete spec into your prompt.
