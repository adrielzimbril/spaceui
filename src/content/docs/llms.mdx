## Overview

Space UI is engineered to be **machine-readable and AI-friendly**. We provide dedicated endpoints that output clean, LLM-optimized markdown without HTML noise or navigation clutter.

### How Per-Component Markdown Works

Every documentation page and primitive can be fetched directly as clean Markdown by prefixing the route with `/llms.mdx/`:

- Example: `https://www.spaceui.one/llms.mdx/ui-kit/primitives/dialog`
- Example: `https://www.spaceui.one/llms.mdx/ui-kit/primitives/tabs`
- Example: `https://www.spaceui.one/llms.mdx/docs/fundamentals/colors`

## Copy Markdown Feature

Every component page in the web UI includes an instant **"Copy Markdown"** button in the header, allowing you to copy the entire page's prompt-ready context into your clipboard in one click.
