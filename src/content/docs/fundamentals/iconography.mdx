## Usage Guidelines

### 1. Tabler in Components & Blocks

When building custom UI sections, feature cards, dashboards, or buttons, import icons from `@tabler/icons-react`:

```tsx
import { IconRocket, IconBrandGithub, IconArrowRight } from '@tabler/icons-react'
import { Button } from '@/components/ui/button'

export function HeroActions() {
  return (
    <div className="flex items-center gap-3">
      <Button>
        <IconRocket className="size-4" />
        <span>Get Started</span>
        <IconArrowRight className="size-4" />
      </Button>
      <Button variant="outline">
        <IconBrandGithub className="size-4" />
        <span>GitHub</span>
      </Button>
    </div>
  )
}
```

### 2. Lucide in Headless Primitives

Primitives use `lucide-react` for standard UI indicators and state controls:

```tsx
import { ChevronDown } from 'lucide-react'
import { AccordionPrimitive } from '@/components/ui/accordion'

export function AccordionTrigger({ children, ...props }: AccordionPrimitive.Trigger.Props) {
  return (
    <AccordionPrimitive.Trigger {...props}>
      {children}
      <ChevronDown className="size-4 shrink-0 transition-transform duration-200" />
    </AccordionPrimitive.Trigger>
  )
}
```

## Icon Sizing Standards

To maintain consistent vertical rhythm across your application, adhere to the standard Space UI icon scale:

| Context                          | Tailwind Class         | Pixel Size  | Stroke Width   |
| :------------------------------- | :--------------------- | :---------- | :------------- |
| **Badges & Micro tags**          | `size-3` or `size-3.5` | 12px – 14px | `1.5` – `1.75` |
| **Buttons & Form Controls**      | `size-4`               | 16px        | `1.75` – `2.0` |
| **Section & Card Headers**       | `size-4.5` or `size-5` | 18px – 20px | `1.5` – `2.0`  |
| **Empty States & Feature Tiles** | `size-8` or `size-10`  | 32px – 40px | `1.25` – `1.5` |

---

## Optical Alignment

When pairing icons with text inside buttons or badges:

- Always apply `shrink-0` to prevent icon distortion inside flex containers.
- Use `pointer-events-none` on decorative icons to ensure click events pass cleanly to the parent trigger.
- Keep icon colors inherited or muted with `text-muted-foreground` to preserve high visual hierarchy on the label text.
