## Files

| File                           | Role                                                                      |
| ------------------------------ | ------------------------------------------------------------------------- |
| `tournament-bracket/index.tsx` | `TEAMS`, rounds data, `MatchBox`, `BracketContainer`, `TournamentBracket` |

Default data is a World Cup–style knockout. Swap `rounds` in the file to feed your own matches (`status`: `upcoming` \| `live` \| `finished`, optional penalties).
