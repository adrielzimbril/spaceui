## Usage

```tsx
import { ImageDark } from '@/components/spaceui/image-dark'
```

```tsx
<ImageDark src="/logo.svg" darkSrc="/logo-dark.svg" alt="Brand Logo" width={48} height={48} />
```

## API Reference

### ImageDark Props

`ImageDark` accepts all standard HTML `<img>` element attributes (`width`, `height`, `loading`, `decoding`, `alt`, `className`, etc.) along with the following:

| Prop        | Type     | Default      | Description                                                                               |
| ----------- | -------- | ------------ | ----------------------------------------------------------------------------------------- |
| `src`       | `string` | **Required** | The primary/light mode image source URL or path.                                          |
| `darkSrc`   | `string` | `undefined`  | The dark mode image source URL or path. Swapped automatically in dark theme.              |
| `alt`       | `string` | `""`         | Alternative text description for accessibility.                                           |
| `className` | `string` | `undefined`  | Additional classes merged onto both image elements (`dark:hidden` / `hidden dark:block`). |
