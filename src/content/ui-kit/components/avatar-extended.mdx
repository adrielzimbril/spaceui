## Anatomy

```tsx
import { Avatar, AvatarImage } from '@/components/ui/avatar'
import {
  AvatarExtended,
  AvatarFallback,
  AvatarRing,
  AvatarBadge,
  AvatarIndicator,
  AvatarIcon,
} from '@/components/spaceui/avatar-extended'

export default () => (
  <AvatarExtended>
    <Avatar>
      <AvatarImage />
      <AvatarFallback>U</AvatarFallback>
    </Avatar>

    <AvatarRing className="ring-primary" />
    <AvatarIndicator className="bg-emerald-500" />
    <AvatarBadge>+6</AvatarBadge>
    <AvatarIcon>
      <IconCheck className="size-3" />
    </AvatarIcon>
  </AvatarExtended>
)
```

## Features

### Verified Icon & Company Logo

Use the `AvatarIcon` component to display small status indicators, verified badges, or company logos at the corner of the avatar.

<ComponentPreview name="demo-p-avatar-06" />

### Avatar Rings

Apply custom selection states or decorative borders using the `AvatarRing` component with standard utility classes.

<ComponentPreview name="demo-p-avatar-03" />

### AvatarFallback

Generates a procedural avatar image from a name via the [SpaceUI Avatars API](https://avatars.spaceui.one). It replaces the primitive `<AvatarFallback>` with a rich, generated image instead of initials.

<ComponentPreview name="demo-p-avatar-10" />

#### AvatarFallback Variants

Pass a `variant` prop to choose a specific style family. Defaults to `'all'` which lets the API pick a random style.

<ComponentPreview name="demo-p-avatar-11" />

### Avatar Badges (Counts)

Display unread notifications or counters cleanly over the avatar using the `AvatarBadge` component.

<ComponentPreview name="demo-p-avatar-08" />

## API Reference

### AvatarFallback

Generates a procedural avatar image from the SpaceUI Avatars API. Extends `React.ImgHTMLAttributes<HTMLImageElement>`.

| Prop      | Type            | Default | Description                                                             |
| :-------- | :-------------- | :------ | :---------------------------------------------------------------------- |
| `name`    | `string`        | -       | The name used to seed the avatar. Falls back to `children` if a string. |
| `variant` | `AvatarVariant` | `'all'` | The visual style family. `'all'` picks a random variant.                |

**`AvatarVariant`** values:

| Family      | Variants                                                               |
| :---------- | :--------------------------------------------------------------------- |
| Gradient    | `lumina` `shaula` `singularity` `triton` `solar-flare` `titan` `glass` |
| Fluid       | `splash` `astronaut` `ghost` `bot` `glitch` `animals`                  |
| Classic     | `pebble` `invader` `grunge` `bored` `doodle` `squiggle`                |
| Paletteless | `critter` `kendo`                                                      |
| All         | `all` (random — default)                                               |

---

### AvatarExtended

The root wrapper component that establishes the relative positioning context. Extends `React.HTMLAttributes<HTMLDivElement>`.

| Prop       | Type        | Default | Description                                                   |
| :--------- | :---------- | :------ | :------------------------------------------------------------ |
| `children` | `ReactNode` | -       | Must contain an `Avatar` and any of the extension components. |

---

### AvatarRing

An absolute overlay that applies a decorative ring or focus outline around the avatar. Extends `React.HTMLAttributes<HTMLSpanElement>`.

_No specific props. Use `className` to pass Tailwind ring utility classes (e.g. `ring-primary ring-offset-2`)._

---

### AvatarIndicator

A small status dot positioned at the bottom right by default, used for online/offline states. Extends `React.HTMLAttributes<HTMLSpanElement>`.

_No specific props. Use `className` to set the color (e.g. `bg-emerald-500`)._

---

### AvatarBadge

A notification counter or badge positioned at the top right. It wraps the standard `Badge` primitive. Extends `BadgeProps`.

| Prop      | Type                                                                                                    | Default     | Description                                         |
| :-------- | :------------------------------------------------------------------------------------------------------ | :---------- | :-------------------------------------------------- |
| `variant` | `"default" \| "destructive" \| "error" \| "info" \| "outline" \| "secondary" \| "success" \| "warning"` | `"default"` | The visual variant of the badge.                    |
| `size`    | `"default" \| "sm" \| "lg"`                                                                             | `"sm"`      | The size of the badge.                              |
| `square`  | `boolean`                                                                                               | `true`      | Forces a square ratio for numbers. Fixed to `true`. |

---

### AvatarIcon

A wrapper used to absolutely position small icons, logos, or verified checkmarks at the bottom right. Extends `React.HTMLAttributes<HTMLDivElement>`.

| Prop       | Type        | Default | Description                          |
| :--------- | :---------- | :------ | :----------------------------------- |
| `children` | `ReactNode` | -       | The icon or logo element to display. |
