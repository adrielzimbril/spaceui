## Usage

```tsx
import { BouncyAccordion } from '@/components/spaceui/bouncy-accordion'

export default function SpaceUI() {
  return (
    <BouncyAccordion
      items={[
        { title: 'Families', description: 'Pick a variant.' },
        { title: 'Capabilities', description: 'Inspect supported effects.' },
      ]}
    />
  )
}
```

## API Reference

### BouncyAccordion

| Prop            | Type                      | Default | Description            |
| --------------- | ------------------------- | ------- | ---------------------- |
| `items`         | `BouncyAccordionItem[]`   | —       | Rows to render         |
| `defaultValue`  | `number \| null`          | `0`     | Initially open index   |
| `value`         | `number \| null`          | —       | Controlled open index  |
| `onValueChange` | `(index: number \| null)` | —       | Fired when a row opens |
| `className`     | `string`                  | —       | Root class             |

### BouncyAccordionItem

| Prop          | Type        | Default | Description      |
| ------------- | ----------- | ------- | ---------------- |
| `icon`        | `ReactNode` | —       | Optional leading |
| `title`       | `string`    | —       | Trigger label    |
| `description` | `ReactNode` | —       | Open panel body  |
