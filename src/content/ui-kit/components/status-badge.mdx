## Usage

```tsx
import { StatusBadge } from '@/components/spaceui/status-badge'
```

```tsx
<StatusBadge status="available" primaryText="Disponible" size="default">
  <Link href="#contact" className="inline-flex items-center gap-1">
    <span>1 place restante pour ce mois-ci</span>
    <ArrowUpRight className="size-3.5" />
  </Link>
</StatusBadge>
```

## API Reference

### StatusBadge Props

| Prop                     | Type                                                                                         | Default     | Description                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------- |
| `status`                 | `"online" \| "available" \| "busy" \| "away" \| "offline" \| "error" \| "warning" \| "info"` | `"online"`  | Semantic status controlling indicator dot color and ping wave color     |
| `primaryText`            | `string`                                                                                     | -           | Primary bold label text shown next to the indicator                     |
| `mode`                   | `"inline" \| "stack"`                                                                        | `"inline"`  | Layout mode (`inline` for badge, `stack` for multi-line card)           |
| `animated`               | `boolean`                                                                                    | `true`      | Enables animated radar ping wave effect                                 |
| `showIndicator`          | `boolean`                                                                                    | `true`      | Whether to display the status indicator dot                             |
| `variant`                | `"default" \| "inverted" \| "outline"`                                                       | `"default"` | Visual style variant for the badge container                            |
| `size`                   | `"default" \| "xs" \| "sm" \| "md" \| "lg"`                                                  | `"default"` | Sizing scale for badge and indicator                                    |
| `indicatorClassName`     | `string`                                                                                     | -           | Custom class name for the indicator dot                                 |
| `primaryTextClassName`   | `string`                                                                                     | -           | Custom class name for the primary text label                            |
| `secondaryTextClassName` | `string`                                                                                     | -           | Custom class name for the secondary text / children                     |
| `indicatorBadge`         | `boolean`                                                                                    | `false`     | In stacked mode, encloses the indicator dot in a square badge container |
