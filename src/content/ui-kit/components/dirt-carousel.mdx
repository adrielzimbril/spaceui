Interactive 3D cylindrical ring carousel. Drag, wheel, or snap between cards. Items, dimensions, and motion physics are configurable via props.

<ComponentInstallation name="components-spaceui-dirt-carousel" />

## Usage

```tsx
import { DirtCarousel, type DirtCarouselItem } from '@/components/spaceui/dirt-carousel'

const items: DirtCarouselItem[] = [
  {
    name: 'Brand',
    mediaType: 'video',
    videoLink: 'https://...',
    thumbnail: 'https://...',
  },
  {
    name: 'Showcase',
    mediaType: 'image',
    imageLink: 'https://...',
  },
]

export default function Example() {
  return <DirtCarousel items={items} radius={800} ballSize={800} bounce={false} snap={true} />
}
```

## Props

| Prop              | Type                       | Default  | Description                                   |
| ----------------- | -------------------------- | -------- | --------------------------------------------- |
| `items`           | `DirtCarouselItem[]`       | `[]`     | Array of media items (video or image).        |
| `direction`       | `'flat' \| 'up' \| 'down'` | `'flat'` | Orbital tilt angle of the 3D ring.            |
| `radius`          | `number`                   | `800`    | Radius of the circular orbit in pixels.       |
| `perspective`     | `number`                   | `800`    | 3D CSS perspective camera distance.           |
| `ballSize`        | `number`                   | `800`    | Size of each carousel item container.         |
| `dragSensitivity` | `number`                   | `0.5`    | Drag speed multiplier.                        |
| `bounce`          | `boolean`                  | `false`  | Floating / bounce animation up and down.      |
| `mouseTilt`       | `boolean`                  | `false`  | Tilts carousel towards the mouse pointer.     |
| `snap`            | `boolean`                  | `true`   | Snaps smoothly to nearest item when released. |
| `autoRotate`      | `boolean`                  | `false`  | Enables continuous automatic rotation.        |
| `autoRotateSpeed` | `number`                   | `0.3`    | Speed of auto rotation (items/second).        |
