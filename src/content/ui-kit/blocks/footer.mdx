## Props

| Prop            | Type                 | Default                                            | Description                           |
| --------------- | -------------------- | -------------------------------------------------- | ------------------------------------- |
| `headline`      | `string`             | `"Let's build something tactile & extraordinary."` | Main callout headline text            |
| `subheadline`   | `string`             | `"Available for select engineering contracts..."`  | Subtitle description                  |
| `brandName`     | `string`             | `'Space UI'`                                       | Brand identity name                   |
| `brandTagline`  | `string`             | `'High-craft UI library...'`                       | Short bio or tagline                  |
| `statusText`    | `string`             | `'Available for Q3/Q4 Projects'`                   | Status beacon label                   |
| `ctaLabel`      | `string`             | `'Get in Touch'`                                   | Action button label                   |
| `ctaHref`       | `string`             | `'mailto:hello@spaceui.one'`                       | Action button link destination        |
| `showCta`       | `boolean`            | `true`                                             | Toggles the top callout row           |
| `showBackToTop` | `boolean`            | `true`                                             | Toggles the back-to-top scroll button |
| `locationName`  | `string`             | `'Paris, FR'`                                      | Location label for the clock chip     |
| `columns`       | `FooterColumn[]`     | `DEFAULT_COLUMNS`                                  | Multi-column navigation links         |
| `socialLinks`   | `FooterSocialLink[]` | `DEFAULT_SOCIALS`                                  | Social media connection buttons       |
