## Key Features

- **Next.js App Router Architecture**: Clean separation between Server Component metadata/SSR and interactive Client Islands.
- **Decoupled Hooks**: `useCustomCursor`, `useHorizontalDrag`, and `useLightbox` are standalone and reusable.
- **Full-Screen Immersion**: Locked to split view with full viewport immersion shortcut (`F` / `Esc`).
- **WebGL Shader Layer**: Fluid Three.js distortion on scroll velocity and hover interactions.
- **Curated High-Resolution Imagery**: Preconfigured with curated photography assets and optimal aspect ratios.
- **Glassmorphism HUD**: Translucent blurred floating dock with category switching, layout mode toggling, and progress counters.
