## Usage

```tsx
import { Button } from '@/components/ui/button'
```

```tsx
<Button>Button</Button>
```

## Link

You can use the [`render`](https://base-ui.com/react/utils/use-render#migrating-from-radix-ui) prop to render another element (like Next.js `Link` or React Router) with button styles.

```tsx
import Link from 'next/link'
import { Button } from '@/components/ui/button'

export function LinkAsButton() {
  return <Button render={<Link href="/login" />}>Login</Button>
}
```

## API Reference

### Button Props

| Prop       | Type                                                                                                      | Default     | Description                                           |
| :--------- | :-------------------------------------------------------------------------------------------------------- | :---------- | :---------------------------------------------------- |
| `variant`  | `"default" \| "destructive" \| "destructive-outline" \| "ghost" \| "link" \| "outline" \| "secondary"`    | `"default"` | Controls the button visual style                      |
| `size`     | `"default" \| "icon" \| "icon-lg" \| "icon-sm" \| "icon-xl" \| "icon-xs" \| "lg" \| "sm" \| "xl" \| "xs"` | `"default"` | Controls the button size                              |
| `loading`  | `boolean`                                                                                                 | `false`     | Shows a spinner and disables the button while loading |
| `disabled` | `boolean`                                                                                                 | `false`     | Disables pointer interactions and dims appearance     |
| `render`   | `React.ReactElement`                                                                                      | -           | Polymorphic render prop (e.g. Next.js Link)           |

When `loading` is `true`, the component:

- Renders a spinner (`data-slot="button-loading-indicator"`)
- Adds `data-loading` on the button root
- Disables interaction and sets `aria-disabled="true"`
- Preserves button layout without jumping
